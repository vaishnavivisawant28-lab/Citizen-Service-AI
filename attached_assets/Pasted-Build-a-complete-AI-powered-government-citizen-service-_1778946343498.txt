Build a complete AI-powered government citizen service portal web application using Next.js, React, Tailwind CSS, Supabase, and Gemini API.

PROJECT GOAL:
Create a secure citizen portal where users can log in and request updates to personal details like mobile number, email address, and residential address. The system should use a RAG-based AI assistant to guide users using retrieved government policy documents and workflows.

TECH STACK:

- Frontend: Next.js + React + Tailwind CSS
- Backend: Node.js API routes
- Database: Supabase PostgreSQL
- Authentication: Supabase Auth
- Vector Database: pgvector in Supabase
- AI Model: Gemini API
- RAG Framework: LangChain
- Deployment-ready structure

MAIN FEATURES:

1. AUTHENTICATION

- Citizen signup/login
- Secure authentication using Supabase
- Session management
- Forgot password
- Logout system

2. CITIZEN DASHBOARD

- Display citizen profile information
- Show:
  - Full name
  - Aadhaar number (masked)
  - Mobile number
  - Email address
  - Address
- Clean modern UI
- Responsive design

3. AI CHATBOT ASSISTANT

- ChatGPT-like interface
- Floating chatbot panel
- User can ask:
  - “How do I change my mobile number?”
  - “What documents are required?”
  - “What is the verification process?”
- AI must answer ONLY from retrieved policy documents
- Use RAG architecture
- Show retrieved document references
- Prevent hallucinations
- If no information found, respond:
  “Official information could not be retrieved.”

4. RAG IMPLEMENTATION

- Create document ingestion pipeline
- Split policy documents into chunks
- Generate embeddings
- Store embeddings in Supabase pgvector
- Retrieve top relevant chunks
- Pass retrieved context to Gemini API
- Include source references in responses

5. PROFILE UPDATE REQUEST SYSTEM
   Allow citizens to request updates for:

- Mobile number
- Email address
- Residential address

Workflow:

- User submits request

- AI assistant explains required verification steps
- Request enters pending approval state
